# Arabic World

An immersion game for learning Arabic, aiming at understanding the Quran. You are a traveller in a Hijazi-style old quarter, making friends and living everyday life in Arabic.

**Public promises:** no faces, modest dress, an all-male cast, no music (only Quran recitation and the adhan). No accounts, ads or analytics; progress stays on your device.

```bash
npm install
npm run dev     # play at http://localhost:5173
npm test        # unit tests + hard-rule suite
npm run lab     # full test-lab cycle and scoreboard
```

Quran text (when added) comes from [Tanzil](https://tanzil.net), used verbatim under CC BY 3.0.
